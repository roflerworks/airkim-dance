# AirKim — презентационный концепт

Адаптивный лендинг студии танца в чёрно-золотой стилистике предоставленного референса. Сделан для показа потенциальному заказчику.

Статический HTML, CSS и JavaScript без сборки. Исходники сайта находятся в `dist/`. Локальный просмотр: `python -m http.server 4173 --directory dist`.

## Публикация

GitHub Actions публикует `dist/` на GitHub Pages после каждого push в `main`. В настройках Pages используется GitHub Actions; HTTPS включён. Домен github.io получает сертификат автоматически. Локальные пути к ресурсам относительные, совместимые с адресом проекта на GitHub Pages.

## Что работает

- Адаптивная навигация с мобильным меню и клавишей Escape.
- Окно записи с выбором интересующего направления, управлением фокусом и закрытием по Escape.
- Звонок по телефону, переход в Instagram и на карты.
- Ссылки на исходные отзывы, плавная навигация по разделам.
- Уменьшение анимации при системном параметре reduced motion.

Форма не отправляет фиктивные заявки: запись осуществляется через указанные контакты.

## Демонстрационные материалы

На первом экране используется предоставленный пользователем ролик Kling с лёгким затемнением через CSS, без звука, с паузой и статичным постером при reduced motion. Ролик оптимизирован до 0,88 МБ. Галерея использует предоставленные пользователем фотографии; их можно открыть крупнее. Портреты педагогов и изображения направлений — AI-иллюстрации для концепта, а не фотографии реальных сотрудников. Имена педагогов и названия направлений взяты из дизайн-референса как демонстрационное наполнение. Перед коммерческим запуском нужно заменить их подтверждёнными сведениями и фото. На странице есть соответствующая пометка, индексация отключена через robots meta.
